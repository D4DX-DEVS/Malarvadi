# Site photography

Drop image files here using the exact filenames below and they appear on the
site automatically. Any file that is missing falls back to an illustrated
gradient panel of the same size, so the layout never breaks.

All slots are rendered by `components/Photo.tsx`.

| Filename            | Used on            | Recommended size |
| ------------------- | ------------------ | ---------------- |
| `hero.jpg`          | Home hero          | 1200 x 900       |
| `highlight-1.jpg`   | Home highlights    | 800 x 600        |
| `highlight-2.jpg`   | Home highlights    | 800 x 600        |
| `highlight-3.jpg`   | Home highlights    | 800 x 600        |
| `about.jpg`         | About hero         | 1000 x 700       |
| `gallery-1.jpg` ... `gallery-8.jpg` | Gallery grid | 800 x 800 |
| `leader-1.jpg` ... `leader-4.jpg`   | Leaders cards | 500 x 500 |
| `news-1.jpg` ... `news-3.jpg`       | News list     | 600 x 450 |
| `event-1.jpg` ... `event-5.jpg`     | Events list   | 600 x 450 |

Formats: `.jpg`, `.png` or `.webp`. Keep each file under ~400 KB.
